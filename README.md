# Drone Missions API

Учебный FastAPI-проект для учёта миссий БПЛА.

## Возможности

- создание миссии;
- получение списка миссий;
- получение миссии по ID;
- изменение статуса миссии;
- удаление миссии;
- хранение данных в SQLite;
- background task для записи событий в лог;
- запуск через Docker.



## Запуск локально

### Установите зависимости

```bash
pip install -r requirements.txt
```

### Запустите сервер

```bash
uvicorn app.main:app --reload
```

После запуска откройте в браузере:
- **http://127.0.0.1:8000/docs** — интерактивная Swagger-документация



## Запуск через Docker

### Соберите образ и запустите контейнер

**Собрать образ:**
```bash
make build
```

**Запустить контейнер:**
```bash
make run
```

После запуска откройте **http://127.0.0.1:8000/docs**

**Остановить и удалить контейнер:**
```bash
make stop
```
